# NBA-Predict — Professional Scoring Analytics

**Summary**
This repository contains a reproducible analysis and predictive pipeline for modeling NBA Points Per Game (PPG) using season-level player data. The project emphasizes interpretable linear modeling, robust feature engineering, and diagnostic validation to support data-driven scouting and roster construction.

**Highlights**
- High explanatory power (reported R² in experiments ~0.92)
- Interpretable features that reflect player roles and physical attributes
- Reproducible notebook-driven workflow for analysis and visualization

- Notebook: [lin_nba.ipynb](lin_nba.ipynb)

**1. Project overview**
This analysis demonstrates an end-to-end approach to modeling offensive production in the NBA. The goal is to produce accurate, explainable predictions of player scoring and to identify the most influential metrics driving outcomes.

**2. Repository layout**
- lin_nba.ipynb — Primary analysis notebook (exploration, modeling, diagnostics)
- data/
	- all_seasons.csv — Compiled season-level player data
- visuals/ — Plots and figures generated by the notebook
- README.md — Project documentation (this file)

**3. Data**
The dataset in `data/all_seasons.csv` contains aggregated season statistics and engineered variables used for modeling. Review the notebook for the exact preprocessing and feature derivation steps.

**4. How to run**
Prerequisites
- Python 3.8+ (3.10+ recommended)
- Install dependencies:

```bash
python -m pip install -r requirements.txt
# If no requirements.txt, install these packages:
python -m pip install pandas numpy scipy scikit-learn matplotlib seaborn jupyter
```

Run interactively
- Open and run `lin_nba.ipynb` with Jupyter or VS Code's notebook interface.

Run headless (optional)
- Convert the notebook to a script or run selected analysis cells using `nbconvert` or `papermill` for automation.

**5. Results & artifacts**
Key figures are stored in the `visuals/` directory:
- 01_eda.png — Exploratory data analysis
- 02_diagnostics.png — Residuals and diagnostic plots
- 03_coefficients.png — Standardized model coefficients and feature importance

Summary metrics (from experiments in the notebook):
- R² ≈ 0.92 — High explanatory power for PPG
- MAE ≈ 1.3 PPG — Low average prediction error

**6. Reproducibility & notes**
- The notebook includes cross-validation and diagnostic checks. Re-run the notebook to regenerate figures and validate results.
- For strict reproducibility, pin package versions in `requirements.txt` and record the Python environment.
